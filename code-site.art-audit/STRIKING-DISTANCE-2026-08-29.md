# Запросы на подступах к топ-10 — что дожимать первым

Источник: GSC, доменный ресурс, 27.05 — 26.08.2026. Полная выгрузка 526 запросов и 148 страниц.
Продолжение [DIAGNOSIS-GSC-2026-08-28.md](DIAGNOSIS-GSC-2026-08-28.md).

**Правило отбора:** позиция 10–30 при показах ≥ 20. Это полоса, где страница уже принята
Google под тему и вопрос только в силе — самые дешёвые победы на сайте.

## 3. Ценовой кластер — много показов, но глубоко

| Запрос | Показы | Позиция |
|---|---|---|
| `вартість сайту` | 42 | **17.7** |
| `сайт ціна` | 20 | **14.4** |
| `ціна сайту` | 14 | **39.5** |
| `просування сайту вартість` | 147 | 70.8 |
| `просування сайту ціна` | 132 | 55.3 |
| `розкрутка сайту ціни` | 127 | 57.1 |
| `створити сайт ціна` | 93 | 71.4 |
| `створення сайту ціна` | 79 | 76.4 |
| `зробити сайт ціна` | 78 | 66.4 |
| `вартість створення сайту` | 60 | 70.6 |
| `вартість розробки сайту` | 57 | 70.9 |

Почти весь кластер за 55-й позицией, и ловит его **`/calculator`** (2 005 показов, позиция
60.5), а не `/pricing`. Причём заметная часть запросов — про **просування** (продвижение), а
не про разработку: `просування сайту вартість`, `розкрутка сайту ціни`, `вартість просування
сайту` 45 показов / 58.8. За них отвечает `/seo` — а она стоит на 63.0 при четырёх показах.

**Вывод.** Ценовой кластер разорван между тремя страницами, ни одна не выигрывает. Прежде чем
наращивать объём `/pricing`, нужно решить, какая страница целевая по «ціна/вартість», и
свести остальные к ней перелинковкой.

## 5. Порядок работ по этим данным

1. **`/sites-for/medicine`** — дожать «під ключ / замовити / створення сайту для клініки» плюс
   блок про дизайн и вёрстку. 24 запроса в полосе 16–30, суммарно ~900 показов.
2. **`/en/sites-for/finance`** — 380 показов на позиции 74.8 при том, что блог по той же теме
   держит 19–25. Страница явно слабее своего блога.
3. **Разобрать ценовой кластер** — определить целевую страницу для «ціна/вартість» и
   развести `/pricing`, `/calculator`, `/seo` по интентам, а не наращивать все три.
4. `/sites-for/renovation` (345 показов, 20.6) и `/sites-for/auto` (106, 26.3) — следующие.

Чего **не** делать: наращивать страницы услуг `/landing`, `/corporate-site`, `/online-store` —
их нет в топе показов вообще (`/landing` 2 показа, `/online-store` 4, `/en/corporate-site` 2).
Спроса на них в поиске сейчас нет, объём им не поможет.

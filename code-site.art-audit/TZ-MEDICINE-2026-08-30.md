# ТЗ: медицинский кластер — почему 2 730 показов дают 2 клика

Дата: 30.08.2026. Источник: полная выгрузка GSC по странице `/sites-for/medicine`
за 3 месяца (112 запросов), проверка URL в GSC, живые замеры страниц.

---

## Что показали данные

`/sites-for/medicine` — крупнейший актив сайта по показам и одновременно худший
по отдаче:

| | |
|---|---|
| Показы за 3 месяца | **2 730** |
| Клики | **2** |
| CTR | **0,07 %** |
| Средняя позиция | **39,8** |
| Объём страницы | 2 661 слово, 17 h2 |

Объём тут ни при чём — страница не тонкая. Дело в другом.

### Наблюдение 1. Узкое совпадение выигрывает, широкое проигрывает

По тем же клиническим запросам две наши блоговые статьи стоят в топ-3, а
коммерческая страница — на третьей странице выдачи:

| Страница | Показы | Позиция |
|---|---|---|
| `/blog/skilky-koshtuye-sait-dlia-kliniky-2026` | 5 | **1,4** |
| `/blog/rozrobka-saitu-medychnoho-tsentru-pid-kliuch` | 11 | **2,8** |
| `/sites-for/medicine` | 574 | **28,7** |

Статьи отвечают на один узкий вопрос и берут топ-3. Страница услуги пытается
закрыть пять разных услуг сразу и не берёт ничего. Это тот же вывод, что дал
разбор конкурентов в августе: на этом рынке выигрывает страница под интент,
а не страница «про всё».

### Наблюдение 2. Страница оптимизирована под худшую из своих формулировок

Разбивка 112 запросов по формулировке:

| Формулировка | Показы | Средняя позиция |
|---|---|---|
| «**клініка**» (сайт для клініки, створення сайту клініки…) | 210 | **16,8–20,7** |
| «медичний сайт» (створення/розробка медичних сайтів…) | 347 | 26,1–47,7 |

Страница ближе всего к топ-10 именно по «клініка». А title и H1 у неё —
«Створення медичних сайтів», то есть под ту группу, которая ранжируется хуже.

### Наблюдение 3. Три интента с показами и без единой страницы

Внутри тех же 112 запросов лежат услуги, которых у нас нет отдельно:

| Интент | Показы | Позиции | Есть страница? |
|---|---|---|---|
| **Дизайн медицинского сайта** | **264** | 22,9–55,7 | нет |
| **SEO для медицинских сайтов** | **174** | 31,5–50,1 | нет (есть только блог) |
| Вёрстка и фронтенд | 172 | 26,8–57,3 | нет |

Дизайн — самый крупный: `веб дизайн для медичних сайтів` 58/27,7 ·
`дизайну сайту медичного центру` 57/32,6 · `веб дизайн медичного центру` 56/45,2 ·
`замовити дизайн для медичного центру` 53/55,7 · `створення дизайну для медичних
клінік` 40/22,9.

### Наблюдение 4. Русская версия страницы мертва

`/ru/sites-for/medicine` — **0 показов за три месяца**. При этом русские
медицинские запросы (152 показа) отдаются украинской страницей на позициях 60–78.

Проверка URL в GSC: страница **проиндексирована**, canonical свой, hreflang
корректный, контент действительно русский. То есть каннибализации локалей нет —
гипотеза №1 из роадмапа по этой странице закрывается отрицательно.

Первое объяснение, которое напрашивалось, — нехватка входящих ссылок: GSC
показывал всего три ссылающиеся страницы. **Проверка его не подтвердила.**
Все семь русских статей медицинского кластера ссылаются на эту страницу; GSC
в поле «Ссылающаяся страница» показывает выборку, а не полный список. Ссылки
не при чём.

Что осталось: H1 русской версии звучал как «Клиника, в которую *записываются*» —
образно и без единого коммерческого слова. Русские запросы при этом почти все
коммерческие: «создание сайта для клиники», «разработка медицинских сайтов»,
«создание медицинского сайта».

### Наблюдение 5. Невалидная Review-разметка примерно на 100 страницах

GSC на `/ru/sites-for/medicine`: «Проверка кода — обнаружен 1 элемент с ошибками».
Ошибка в узле `Review`:

```json
{ "@type": "Review", "itemReviewed": { "@id": "https://www.code-site.art/#organization" } }
```

Отзыв об **этой же** организации на её собственном сайте. Google такие отзывы не
поддерживает: self-serving reviews про Organization и LocalBusiness исключены из
rich results с 2019 года, а `Organization` вообще нет в списке типов, для которых
поддерживается review snippet.

`buildReviewNodes(seeds, ORG_ID)` вызывается с главной (3 локали), со всех страниц
отраслей и со всех кейсов — то есть разметка, которая никогда не даст сниппет и
при этом числится ошибкой, стоит примерно на сотне страниц.

---

## Что делаем

### 1. Убрать Review-разметку, ссылающуюся на свою же организацию

Отзывы на страницах остаются как были — уходит только разметка, которая не может
дать результата и портит отчёт GSC. `buildReviewNodes` перестаёт принимать
`ORG_ID` как `itemReviewed`.

### 2. Переориентировать `/sites-for/medicine` на «клініка»

Title и H1 — на формулировку, по которой страница уже стоит на 16,8–20,7.
«Медичні сайти» остаются в тексте и подзаголовках, но перестают быть главным
сигналом страницы.

### 3. `/sites-for/medicine/dyzain` — дизайн медицинского сайта

264 показа без собственной страницы. Формат — подстраница медицины, как уже
существующие `stomatolohiia` и `medychnyi-tsentr`.

Не дорвей: дизайн клиники — это отдельная работа со своим содержанием (сетка
доверия, фото врачей, подача цен, доступность), а не пересказ страницы разработки
другими словами.

### 4. `/sites-for/medicine/seo` — продвижение медицинских сайтов

174 показа. Разводим интенты: `/seo` — общая услуга, блог
`seo-dlia-medychnykh-saitiv` — как сделать самому, новая страница — заказать
продвижение клиники.

### ~~5. Перелинковать русскую медицину~~ — отменено

Проверка показала, что все семь русских медицинских статей уже ссылаются на
`/ru/sites-for/medicine`. Три ссылки в отчёте GSC были выборкой, а не полным
списком. Делать нечего.

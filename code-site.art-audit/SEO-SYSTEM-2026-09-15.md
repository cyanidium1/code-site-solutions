- **Глубина кликов от главной:** 88 URL на 1 клике, 136 — на 2, 66 — на 3, 9 — на 4. На 4-м клике
  оказался и `/en/blog/custom-website-vs-wordpress-2026`, у которого 277 показов на позиции 12,3.
- **Нишевые посты** (12 тем × 3 языка = 36 URL: психолог, салон красоты, фотограф, ресторан, школа,
  фитнес, отель, мебель, турагентство, грузоперевозки, кондитер, агентство недвижимости) доступны
  только через пагинацию блога, со страниц 3–5. **28 из них не получают ни одной ссылки из контента.**
  Посты ссылаются на отраслевые хабы, но хабы на посты — нет.
- **URL-схема** в целом последовательная. Две шероховатости: RU-хаб разработки живёт на украинской
  транслитерации (`/ru/rozrobka-saitiv`), медицинские подстраницы есть только в UA.
- **Индексация:** 312 страниц в индексе, 63 нет. Из этих 63: обнаружена, не проиндексирована — 25;
  просканирована, не проиндексирована — 13; 404 — 9 (валидация начата); редирект — 9; noindex — 7.

# 5. Усиление приоритетных страниц

## 5.1. `/pricing` — цена разработки (кластер A)

**Реальный интент.** «Скільки коштує зробити/створити сайт», «створення сайту ціна», «вартість сайту під ключ».
Человек хочет увидеть число в гривнах на первом экране, разброс по типам сайтов и состав пакета.
В выдаче (разбор 31.08) побеждают прайс-таблицы с гривнами, рейтингом и датой обновления. Калькуляторов в топе нет.

**Структура — новый порядок:**
1. H1 и ответ одним абзацем: «Сайт у 2026 коштує від $800 (≈35 600 грн) за лендінг до $6 000+ за платформу», дата обновления.
   Сразу таблица: тип · $ · грн · срок · главное, что входит.
2. **Скільки коштує кожен тип сайту:** лендінг, корпоративний, інтернет-магазин, каталог, веб-додаток. Каждая строка
   ссылается на свою услугу — так `/pricing` передаёт вес `/landing`, `/corporate-site`, `/online-store`.
3. **Що входить і що не входить** — два нынешних H2 свести в одну таблицу.
4. **Від чого залежить ціна** — свести «Чому вартість не одна цифра» и «Як ми рахуємо»: таблица факторов с ± $.
5. **Окремі послуги:** дизайн, редизайн, верстка, обслуговування, SEO — с ценами и ссылками на `/redesign`, `/support`, `/seo`.
   Этот раздел закрывает кластеры J и K и уводит их на свои страницы, не делая `/pricing` целью для них.
6. **Витрати поза студією** — оставить.
7. **Реальні кошториси** — три кейса из портфолио с суммой и составом.
8. **Конструктор, фрілансер чи студія** — сократить до таблицы, ссылки на `/vs-*`.
9. **Для вашої сфери** — оставить, ссылки на `/sites-for/*`.
10. FAQ, CTA.

**Убрать или слить:** «Чому дешевий сайт часто виходить дорожчим» → в FAQ, оно дублирует `/vs-freelancers`.
«Не впевнені, який пакет підходить?» дублирует финальный CTA.

## 6.2. Правила

1. **Один интент — один целевой URL — один анкор.** «Ціна сайту» → `/pricing`. «Ціна просування» → `/seo`.
   «Вартість обслуговування» → `/support`. Калькулятор получает анкоры только со словом «калькулятор».
2. **Хабы ссылаются вниз.** Каждый `/sites-for/*` ведёт на свои посты. Сейчас ссылки идут только вверх.
3. **Родитель медицины ↔ дети, с якорями под интент:** «дизайн сайту медичного центру» → `/dyzain`,
   «верстка медичних сайтів» → `/verstka`, «SEO для клінік» → `/seo`, «сайт для стоматології» → `/stomatolohiia`,
   «сайт медичного центру під ключ» → `/medychnyi-tsentr`. Дети ведут на родителя («створення сайту для клініки») и на `/pricing`.
4. **Глоссарий ведёт на услугу — одна контекстная ссылка:**
   - «що таке лендінг» → `/landing`
   - «що таке SEO», «AI-пошук», «llms.txt» → `/seo`
   - «CMS», «адмін-панель» → `/corporate-site`
   - «Core Web Vitals», «швидкість» → `/audit`
   - «домен», «хостинг» → `/support`
   - «CTA», «конверсія», «юзабіліті» → `/redesign`
5. **Сквозной путь:** информационный пост → хаб отрасли или услуги → `/pricing` или калькулятор → бриф.
   В каждом посте ровно один основной CTA-переход — на хаб, не на `/contacts`.
6. **Локали:** RU-страницы ссылаются только на RU-версии. Там, где RU-версии нет (`/about`, `/vs-*`, `/support`),
   либо создать её, либо ссылку убрать.
7. **Блог:** на `/blog` добавить рубрики по отраслям. Тогда нишевые посты окажутся в двух кликах от главной, а не в трёх-четырёх.
